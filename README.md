# Третя доба

Інтерактивна новела для практичного заняття «Стрес і травматична відповідь». Специфікація: `docs/spec.md`, завдання: `docs/task.md` і `docs/task_v2.md`.

Запуск: двічі клацнути `index.html` (працює з диска, без сервера та інтернету).

Керування: варіанти А, Б, В мишею або клавішами 1, 2, 3. «Далі» мишею, пробілом або Enter. «Назад» мишею або Backspace (є на кожному екрані, крім першого екрана вступу).

Розробка:

- `node tools/build-scenario.js` перегенерує `scenario.js` з `data/scenario.json` (після кожної правки текстів).
- `node tools/test-engine.js` звіряє рушій з 25 еталонними шляхами (фінал, шкали, вирази на кожному кроці), з розподілом фіналів у розділі 10 специфікації, з графом виразів і з `reference/engine.py` на кожному з 229 203 шляхів (через `tools/enumerate.py`, потрібен python3).
- `NODE_PATH=$(npm root -g) node tools/test-ui.js` у headless Chromium (потрібен Playwright): три контрольні шляхи з виразом на кожному екрані, компонування без прокручування для кожного варіанта і гілки умови, кнопка «Назад» (30 випадкових шляхів і повернення через флешбек, N6B, обрив, вхід у другу сесію, епілог), скріни в `screenshots/`.
