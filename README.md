# Третя доба

Інтерактивна новела для практичного заняття «Стрес і травматична відповідь». Специфікація: `docs/spec.md`, завдання: `docs/task.md`.

Запуск: двічі клацнути `index.html` (працює з диска, без сервера та інтернету).

Керування: варіанти А, Б, В мишею або клавішами 1, 2, 3. «Далі» мишею, пробілом або Enter.

Розробка:

- `node tools/build-scenario.js` перегенерує `scenario.js` з `data/scenario.json` (після кожної правки текстів).
- `node tools/test-engine.js` звіряє рушій з 25 еталонними шляхами і з розподілом фіналів у розділі 10 специфікації (повний перебір 229 203 шляхів).
- `NODE_PATH=$(npm root -g) node tools/test-ui.js` проходить три контрольні шляхи в headless Chromium (потрібен Playwright), перевіряє вирази обличчя, фінали, обрізаний текст і зберігає скріни в `screenshots/`.
