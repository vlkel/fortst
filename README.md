# Третя доба

Інтерактивна новела для практичного заняття «Стрес і травматична відповідь». Специфікація: `docs/spec.md`, поточне завдання: `docs/task_v3.md` (попередні: `docs/task.md`, `docs/task_v2.md`).

Запуск: двічі клацнути `index.html` (працює з диска, без сервера та інтернету).

Керування: клік по сцені, пробіл або Enter показують наступний фрагмент тексту. Варіанти А, Б, В мишею або клавішами 1, 2, 3. «Назад» мишею або Backspace повертає на один фрагмент (через меню вибору скасовує вибір повністю).

Розробка:

- `node tools/build-scenario.js` перегенерує `scenario.js` з `data/scenario.json` (після кожної правки текстів).
- `node tools/test-engine.js`: 25 еталонних шляхів із `reference/golden_paths.json` (фінал, шкали, R, вирази на розповіді, репліці, після вибору і в сцені обриву, оцінка, гілка), повний перебір 229 203 шляхів (розподіл фіналів із розділу 10 специфікації, граф виразів на кожному екрані, гнів лише після 5), побайтова звірка з `python3 reference/enumerate_paths.py`, поділ усіх текстів на фрагменти.
- `node tools/enumerate.js > js_paths.txt` друкує повний перебір у форматі `reference/enumerate_paths.py`.
- `NODE_PATH=$(npm root -g) node tools/test-ui.js` у headless Chromium (потрібен Playwright): три контрольні шляхи в 1280×720 і 1920×1080 з виразом і текстом на кожному екрані, макет (голова над текстовим полем, текст у полі, меню над полем, цілі шрифти), усі фрагменти і меню, кнопка «Назад» (30 випадкових шляхів і повернення через флешбек, N6B, обрив, вхід у другу сесію, епілог), скріни в `screenshots/`.
